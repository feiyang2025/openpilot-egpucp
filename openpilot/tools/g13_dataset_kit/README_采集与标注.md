# G13 采集与标注规范(三层巡检第三章,主动避让20261112.md §6.6 原文摘录要点)

## 为什么不是"多拍点就行"
召回的上限在数据里,不在模型里。两颗雷必须排掉:
1. **按帧划分 = 报告值虚高 5-15 pt**:划分永远按 路线×日期×场景;相邻帧跨集是头号作弊。
2. **总体 mAP 盖小箱**:逐箱定额,缺箱即红,不许用平均分放行。

## 箱(box)结构与定额(§3.4 反推)
箱 = {站立(成人/儿童/骑行/摩托), 低矮(锥桶/碎片/动物), 信号(留存,tl 模型已覆盖)} × {30-40, 40-55, 55-70 m} × 类别
- 每箱 n ≥ n(α,p)=ln(α)/ln(1-p);按预注册的检出概率 p 逐箱填(check_boxes.py 管账)。
- 采集时用"目标帧上像素高"反推距离:detPxH(1280 域) = 1372×h/D → 30-40m 成人≈38-50px、儿童≈34-45px;55-70m 成人≈20-27px(已低于门,仍是采集重点——门内难例即长尾,标了训练才有机会)。
- **近箱(0-30m)** 不硬性要求,但 mixup/copy-paste 增广请在 ODD 内按真实尺度(缩远处目标补箱 = 注水,该箱作废)。

## 标注规则
- YOLO 格式 cls cx cy w h(归一化,全帧 1920×1080 坐标;letterbox 由训练侧处理)。
- **框贴目标本体**:上下留白 ≤ 物高 5%;宁可紧勿松(检测头照你框的样子学)。
- 5-30px"疑似有物未框"第三遍 100% 回扫:漏标 = 训练侧假阴性返巢(杀召回)。
-遮挡目标:可见部分 ≥ 50% 才标,occlusion 写入标注备注;模糊(运动/夜)不丢——难例就是在这收的。
- 一个目标只属于一个类;电动车(两轮带脚踏)归 cyclist,燃油摩托归 motorcycle;拿不准的进仲裁桶,不许拍脑袋。

## 四方隔离
train / val / test / calib 四集;**calib 专供 INT8 标定与 ΔAP 门分母**,不得混入 train。
test 生成后立即 sha256 封存(写入预注册 commit);test 只读——后续挖掘出的 test 片段必须移出并留痕。

## 每类最低采集重点(先成本最低的三档顺手)
类       | 重点
-------- | -----------------------------------------------------------
cone     | 施工区/锥桶引导线,10-60m,倒伏+立姿都要
debris   | 轮胎皮/纸箱/泡沫,路面散落,最容易漏标的一类
child    | 1.0(修订24 下界)-1.4m;小区/学校门口;背光/黄昏多收
animal   | 散养犬/猫横穿,10-40m
cyclist  | 逆行者、夜无灯者(高价值难例)
adult    | 特意难例为主:打伞/推车/侧身/挡半截;普通成人靠 COCO 热启

## 诊断工具
boxes.json 是逐箱配额账(p_assumed 预注册值 + n_actual 采集实况),check_boxes.py 判红绿:
python check_boxes.py boxes.json        # 全箱齐→exit 0;缺箱→红 exit 1(G13 骨架)
